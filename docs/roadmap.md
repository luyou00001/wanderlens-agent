# 後續順序

目前的版本故意停在可審閱的本機產物。`wanderlens ui` 可以打開監控頁，查看索引摘要與模型清單；它不會發佈，也不會顯示座標。建議依這個順序往下做，而不是同時打開商店、影片與所有模型。

1. 用 10 到 50 張你自己的照片跑完 `ingest`、`describe`、`draft`、`export-posts`，確認 EXIF 與行程分組符合預期。
2. 在伺服器上只啟動一個視覺模型，先重跑這 10 張。比較技術預檢與模型描述，再調整 `config/prompts/vision_json.txt`。
3. 你親自讀過草稿後，才對個別檔案使用 `mark-publish`。貼上平台仍由你操作。
4. 圖庫變大之後，再加入 SigLIP 2 或 DINOv2 索引，以及鏡頭切分。這兩個適配器都還沒寫。
5. 只有在靜態影像的權利與人物判斷穩定之後，才做販售草稿包，並由你手動上傳。
6. 官方發佈 API 要等你擁有對應的開發者帳號，而且每次送出前仍保留人工確認。

暫不排入的項目：自動登入社群網站、模擬留言或互動、由畫面猜測私人位置、人臉身分庫，以及把生成音樂放進商品。
