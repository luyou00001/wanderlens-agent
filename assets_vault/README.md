# 素材庫

請把照片與影片放進 `inbox/`，或在 Linux 伺服器上把既有碟位掛載到這個目錄。程式會遞迴讀取子資料夾。

支援的照片副檔名：`.jpg`、`.jpeg`、`.png`、`.webp`、`.tif`、`.tiff`、`.heic`、`.heif`。
HEIC 需要在伺服器另外安裝解碼器；尚未安裝時，檔案仍會被登記，並標上無法解碼。

支援的影片副檔名：`.mp4`、`.mov`、`.m4v`、`.avi`、`.mkv`、`.webm`。
抽幀需要系統已安裝 `ffmpeg` 與 `ffprobe`。

此目錄的內容已在 `.gitignore` 排除，不會被提交。請保留原始檔，程式只在匯出時另存一份去掉 GPS 的 JPEG。
